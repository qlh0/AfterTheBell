# v0.4 两天时间线与日常插曲 — 本地验收

## 目标

- 剧情从约 14 轮扩展到约 20 轮，**第 22 轮必须结束**；
- 增加第二天，四段主场景必须能在推进中出现；
- 增加三个日常插曲：图书馆、走廊、小卖部；
- 插曲可以由对话提示触发，也可以由玩家直接说出场景名触发；
- 强制收束前必须有有效对话/旁白，不允许直接黑屏。
- 新场景先用占位背景，正式图后续同名覆盖。

## 实现

### 场景与天数

`game_state.py`：

- `SCENES = classroom, school_gate, corridor, library, shop`
- `day = 1/2`
- `SCENE_FLOW`：
  - 第一天教室 → 第一天校门口
  - 第一天校门口 → 第二天教室
  - 第二天教室 → 第二天校门口

`engine.py`：

- `advance()` 按 `SCENE_FLOW` 推进；插曲场景结束回到 `return_scene`；
- `_maybe_auto_advance()` 在关键回合（5/10/15）自动推进，保证四段主场景在预算内出现；
- `presentation.scene_id` 对第二天教室/校门口映射为 `classroom_day2` / `school_gate_day2`；
- 客户端底部显示“第一天 / 第二天”。

### 预算与收束

- `content/narrative_goals.json`：预算 19，soft 18，hard 22；
- `game_state`：soft = budget-1，hard = budget+3；
- 第 20 轮起进入校门口收束，激活 finale；第 22 轮无论证据如何都提交结局；
- 收束时保留角色回复 + 旁白（“她说完最后一句……”或“她看着你……”），再进入结局卡。

### 新 Storylet

| id | 场景 | 触发 | 结果 |
|---|---|---|---|
| `library_study` | 教室 → 图书馆 | 提示 / 关键词「图书馆、自习」 | studied_together / studied_quietly / left_early |
| `corridor_chat` | 教室 → 走廊 | 提示 / 关键词「走廊、窗边」 | chatted / awkward / interrupted |
| `shop_trip` | 校门口 → 小卖部 | 提示 / 关键词「小卖部、买东西」 | bought_together / ran_into_classmate / went_alone |

- 三个事件 `manual_only=true`，不进入导演随机候选；
- `enter_scene` / `return_scene` 自动进出场景；
- 插曲激活当轮只铺情境，至少下一轮才结算。
