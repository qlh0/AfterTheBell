# v0.4 两天时间线与日常插曲 — 本地验收

## 目标

- 剧情从约 14 轮扩展到约 20 轮，**第 22 轮必须结束**；
- 增加第二天，四段主场景必须能在推进中出现；
- 增加三个日常插曲：图书馆、走廊、小卖部；
- 插曲可以由对话提示触发，也可以由玩家直接说出场景名触发；
- 强制收束前必须有有效对话/旁白，不允许直接黑屏。
- 新场景素材已接入；第一天/第二天共用同一张教室/校门口背景。

## 实现

### 场景与天数

`game_state.py`：

- `SCENES = classroom, school_gate, corridor, library, shop`
- `day = 1/2`
- `SCENE_FLOW`：
  - 第一天教室 → 第一天校门口
  - 第一天校门口 → 第二天教室
  - 第二天教室 → 第二天校门口

`engine.py`：

- `advance()` 按 `SCENE_FLOW` 推进；图书馆/走廊结束回校门口，小卖部默认留在小卖部；
- `_maybe_auto_advance()` 在关键回合（5/15/18）自动推进，保证四段主场景在预算内出现；
- `presentation.scene_id` 直接使用 `state.scene`；`day` 只用于日期显示，不再生成 `_day2` 背景；
- 客户端底部显示“第一天 / 第二天”。

### 预算与收束

- `content/narrative_goals.json`：预算 19，soft 18，hard 22；
- `game_state`：soft = budget-1，hard = budget+3；
- 第 20 轮起进入校门口收束，激活 finale；第 22 轮无论证据如何都提交结局；
- 从第一天跨到第二天时，客户端黑屏显示「第二天 / 放学后」，再进入第二天教室；
- 转场文案：`Day 01 - END` → 「有些话，今天还没能说出口。\n不过，明天也还能见面。」→ 全部淡出 → `DAY 02 — 放学后`；
- 第一天的告别旁白与「第二天放学后，教室里只剩下你们两个。」拆成两屏：后者保存为 pending，在下一次操作（转场后）的第一回合展示，不会挤在第一天；
- 玩家在第一天校门口说「明天见 / 先走了 / 路上小心」时，她会顺势收束到第二天；
- 即使没说，第一天校门口到第 15 轮也会由她主动说「明天放学后见」并转场。
- 插曲进入后至少停留两轮玩家回应；小卖部结束默认留在小卖部，玩家说「回校门口」才返回。
- 收束时保留角色回复 + 旁白（“她说完最后一句……”或“她看着你……”），再进入结局卡。

### 新 Storylet

| id | 场景 | 触发 | 结果 |
|---|---|---|---|
| `library_study` | 教室 → 图书馆 | 提示 / 关键词「图书馆、自习」 | studied_together / studied_quietly / left_early |
| `corridor_chat` | 教室 → 走廊 | 提示 / 关键词「走廊、窗边」 | chatted / awkward / interrupted |
| `shop_trip` | 校门口 → 小卖部 | 提示 / 关键词「小卖部、买东西」 | bought_together / ran_into_classmate / went_alone |

- 三个事件 `manual_only=true`，不进入导演随机候选；
- `enter_scene` / `return_scene` 自动进出场景；
- 插曲激活当轮只铺情境，至少两轮玩家回应后才结算。

### 分班对白约束

- 玩家问「分班填了什么/准备去哪/怎么想」时，回复必须落到具体方向（理重点班/物理方向/还在犹豫）；
- 服务端会拒绝「随便报」「查户口」「问这个干嘛」以及只回答「还是这学校」的回复，要求模型重写一次；
- 仍不合格时退回模板对白，模板只保留具体回答；
- `class_talk` 只有听到具体方向才记为「谈过分班」，避免「填了张表」被误判；
- 禁止用「话到嘴边又忘了」「欲言又止」拖节奏；第一次命中要求重写，仍命中则退回模板对白。
